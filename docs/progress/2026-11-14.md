  - `internal/capabilities`: Evidence-backed capability engine (`Available`, `RequiresHardware`, `FirmwareTooOld`, `NotExposedCLI`, `Unsupported`, `Unknown`).

  - `internal/survey`: Wi-Fi AP and station survey engine with deduplication, RSSI statistics, and channel distribution.
  - `internal/monitor`: Channel histogram, beacon/probe/deauth anomaly detection.
  - `internal/capture`: Streaming PCAP parser, packet framing, and SD card import.
  - `internal/ble`: BLE device observation, manufacturer decoding, and tracker detection.
  - `internal/gps`: NMEA sentence parser, GPX track visualizer, and wardriving session import.
  - `internal/policy`: Isolated Authorized Lab policy gate with consent verification, target allowlisting, session timeouts, and local audit logging.
  - `internal/firmware`: Board target catalog, partition validator, and dry-run flashing preflight safety checks.
  - `internal/store`: Embedded SQLite store for device configurations, survey snapshots, and audit trail.
  - `internal/reports`: Sanitized JSON, CSV, and HTML report generator.
  - `internal/diagnostics`: Sanitized support bundle generator.
  - `internal/app`: Wails desktop application controller and frontend bridge.
  - `frontend`: Modern responsive Svelte + TypeScript + Tailwind UI featuring 12 navigable workspaces, live tables, sparklines, and Emergency Stop controls.
  - `.github/workflows/ci.yml`: Comprehensive CI for Go and Frontend testing on Ubuntu, macOS, and Windows.
  - `.github/workflows/release.yml`: Release on tag workflow building macOS, Windows, and Linux binaries with SHA-256 checksums and automated GitHub Release publication.
