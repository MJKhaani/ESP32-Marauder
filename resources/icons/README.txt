MARAUDER STUDIO — macOS APP ICON

Files:
- Marauder_Studio.svg: editable resolution-independent vector master
- Marauder_Studio_1024.png: 1024×1024 RGBA PNG with transparent outer corners
- Marauder_Studio.icns: packaged macOS icon file
- Marauder_Studio.iconset/: all standard macOS iconset PNG sizes (16–1024px)

To use in a macOS .app bundle:
- Put Marauder_Studio.icns into YourApp.app/Contents/Resources/
- Set CFBundleIconFile to Marauder_Studio in Info.plist

Or in Xcode, drag appropriately sized iconset PNG assets into AppIcon in Assets.xcassets.

The vector source was designed specifically for Marauder Studio.
